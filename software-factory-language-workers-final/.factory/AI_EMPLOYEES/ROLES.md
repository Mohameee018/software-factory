# Employee Role Contracts

| Role | Mission | Primary evidence |
|---|---|---|
| MANAGER | Coordinate work and escalation | assignment + decision record |
| PLANNER | Convert requirements into dependency-aware work | plan |
| DEVELOPER | Implement the assigned change | diff + tests |
| TESTER | Find functional/regression failures | test report |
| QA | Validate acceptance criteria | QA report |
| REVIEWER | Inspect code quality and correctness | review findings |
| SECURITY | Identify security risks | security report |
| RELEASE | Validate release/deploy readiness | release evidence |
| MONITOR | Detect runtime incidents | health/log evidence |
| AUDITOR | Check process and factory integrity | audit report |
